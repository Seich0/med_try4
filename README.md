# Лекарственный навигатор

Отдельное Streamlit-приложение для поиска информации о препаратах. Координатор запускает агенты DailyMed и EMA, валидатор проверяет совпадение с запросом, а агент подготовки фрагментов сокращает длинные разделы для показа.

- DailyMed ищет инструкции к препаратам по названию через API. Период задаётся по дате публикации. Для найденных инструкций приложение загружает структурированный SPL XML и показывает сокращённые фрагменты показаний, противопоказаний и предупреждений, если эти разделы присутствуют. Фрагменты могут быть неполными; полную инструкцию нужно открывать по ссылке.
- EMA ищет страницы EPAR по официальной JSON-выгрузке и показывает сведения о показаниях; если доступен раздел рисков в обзоре EPAR, показывает его фрагмент. Период задаётся по дате обновления страницы. PDF SmPC приложение не анализирует; полученные фрагменты не являются полным списком противопоказаний и рисков.
- Для обоих источников предусмотрены рубрики «Показания и применение» и «Предупреждения и риски». Для DailyMed также отображается рубрика «Противопоказания». Если отдельного раздела нет в извлечённых данных, приложение сообщает об этом; это не означает отсутствие противопоказаний или рисков. Для EMA противопоказания следует проверять в полной информации по ссылке на источник: приложение не извлекает их отдельным разделом из PDF.

## Запуск

Нужен Python 3.12. Установите зависимости из `requirements.txt` и выполните:

```powershell
python -m streamlit run streamlit_app.py
```

Для Streamlit Community Cloud загрузите файлы этой папки в репозиторий GitHub, выберите `streamlit_app.py` и Python 3.12 в Advanced settings.
